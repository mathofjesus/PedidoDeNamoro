# Skills — PedidoDeNamoro

Página interativa de pedido de namoro — HTML, CSS, JS. Single file.

## Project facts

- Single static file: `index.html` (all HTML + CSS + JS inline). No build step.
- Open in browser or deploy to any static host (Vercel, Netlify, GitHub Pages, etc.).
- The "Não" button runs away on `mouseover` and `click` (`moveNoButtonRandomly()` at `index.html:339`).
- The "Sim" button hides the question and reveals the answer section.
- Spotify playlist ID is hardcoded in JS (`index.html:334`). Default: `37i9dQZF1DX50QitC6Oqtn`.
- Person name is "Mary" — appears in the heading and floating texts.
- Responsive layout with a breakpoint at 600px.
